# hxyfront-62011 马术蹄铁修整档案

源提示词编号：6

做一个面向马术俱乐部蹄铁师的修蹄记录前端项目，可以记录马匹编号、步态问题、蹄形评估、蹄铁类型、钉位、修蹄日期、下次复查日期和照片备注。页面需要有马匹列表、复查提醒、左右前后蹄对比记录、异常步态标记和蹄铁更换历史。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62011

## 功能

- **马匹档案**：编号、名字、运动马/休养马分类，所有档案保存在浏览器 localStorage（首次打开自动生成示例数据）。
- **修蹄登记**：左前、右前、左后、右后四个蹄位分别填写步态问题、蹄形评估、蹄铁类型、钉位、照片备注并可上传压缩后的现场照片；四蹄均记录完整才能归档。
- **异常步态**：修蹄时勾选标记；复查时先展示上次评估，必须逐蹄录入本次变化才能结束复查，可勾选“步态已恢复正常”解除标记。
- **马匹列表**：按编号搜索，支持前蹄问题 / 后蹄问题 / 待复查筛选（待复查取最近一次未复查的修蹄）。
- **复查提醒**：侧栏按下次复查日期先后排列，逾期/临期高亮；顶部“待复查”指标可一键跳转。
- **蹄铁更换历史**：每次更换蹄铁按蹄位留档，马匹档案内提供类型、钉位、备注的完整流水表，以及历次修蹄四蹄对比与复查变化。
