# hxyfront-62011 马术蹄铁修整档案

面向马术俱乐部蹄铁师的单页修蹄记录应用，替代纸质卡片与聊天记录。数据保存在浏览器本地（localStorage），无需后端。

## 功能

- **马匹档案**：编号、马名、类别；按马匹编号搜索，支持“全部 / 前蹄问题 / 后蹄问题 / 待复查”筛选。
- **四蹄分别登记**：左前、右前、左后、右后各自填写蹄形评估、蹄铁类型、钉位、照片备注（可拍照上传，自动压缩）。
- **完整才可归档**：一次修蹄必须四蹄的评估、蹄铁类型、钉位全部填写，缺项会逐蹄标红并阻止归档。
- **异常步态复查**：被标记异常步态的马，复查时先展示上次四蹄评估；必须录入“本次变化”才能结束复查。
- **复查提醒**：按复查日期先后排列，自动区分逾期 / 今日 / 7 天内 / 之后，可一键开始复查。
- **蹄铁更换留档**：相邻两次记录间任一蹄位蹄铁类型变化都会自动记入“蹄铁更换历史”，马匹档案可查看历次类型、钉位、照片备注的完整历史。

## 技术栈

React 19 + Vite + TypeScript（本地存储 + 图片 canvas 压缩）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62011

构建：`npm run build`（类型检查可单独运行 `npx tsc --noEmit`）
